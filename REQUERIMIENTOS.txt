1) REQUISITOS DEL SISTEMA
------------------------------------------------------------------------
- Sistema operativo : Windows 10/11 x64 (probado en Windows 11 IoT
                     Enterprise LTSC, build 26100)
- Consola           : PowerShell 7.x (probada 7.6.9). Usada por
                     scripts/iniciar.ps1, scripts/detener.ps1 y
                     scripts/generar-integridad.ps1
- XAMPP             : panel con el servicio MariaDB activo
                       * PHP 8.2.33 (CLI)        -> API PHP (puerto 8000)
                       * MariaDB 10.4.32         -> base de datos (puerto 3306)
                       * binario: C:\xampp\mysql\bin\mysql.exe
- Node.js           : v24.19.0  (npm 11.17.0)
                       Gateway (3000), API Node (3002), Frontend (8443)
- Python            : 3.13.15  (API Python FastAPI en puerto 3003)
- Navegador         : Chrome/Edge/Firefox actualizados (HTTPS local,
                     JavaScript, canvas para graficas Chart.js)

2) PUERTOS
------------------------------------------------------------------------
  3000  API Gateway (HTTPS con certificado pfx)    node   api-gateway
  3002  API de alquileres e inspecciones (HTTP)    node   apis\apinode
  3003  API de maquinarias/unidades/reportes       python apis\apipython
  8000  API de captcha y sesion (HTTP)             php    apis\apiphp
  8443  Frontend (HTTPS con certificado pfx)       node   frontend-server
  3306  MariaDB InnoDB utf8mb4_unicode_ci          XAMPP  basededatos

  Nota: la instancia MariaDB del 3306 es COMPARTIDA con otro proyecto
  (pos_app): scripts/detener.ps1 nunca la apaga ni rota su clave root.

4) COMO REINSTALAR DEPENDENCIAS
------------------------------------------------------------------------
    cd api-gateway   && npm install
    cd apis\apinode  && npm install
    pip install -r apis\apipython\requirements.txt
    (el frontend no requiere instalacion: usa vendor local)
    (la demo movil es opcional: npm install && npx expo start)

5) ARRANQUE Y APAGADO
------------------------------------------------------------------------
    iniciar.bat
        [1 de 2] scripts\detener.ps1  -> libera puertos del proyecto
                                         (3000/3002/3003/8000/8443/8082)
                                         y DEJA VIVO el MariaDB del 3306
        [2 de 2] scripts\iniciar.ps1  -> siembra la BD si hace falta,
                                         levanta las 6 piezas y hace
                                         checks de salud
    Detener a mano: scripts\detener.ps1  (o cerrar iniciar.bat)
